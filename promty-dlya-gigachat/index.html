Промты для GigaChat

GigaChat — нейросеть Сбера. Работает в России без ограничений: на сайте, в приложении, в мессенджерах и через API с оплатой в рублях. Хорошо понимает русский язык и российский контекст, умеет рисовать картинки.

Совет: промты из Промтотеки написаны на русском, поэтому подходят GigaChat без переделки. Для картинок используйте шаблоны из раздела «Изображения» — описывайте объект, стиль и свет.
