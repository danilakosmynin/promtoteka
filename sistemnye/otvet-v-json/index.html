Ответ в JSON

Для программ и автоматизаций.

Отвечай только валидным JSON без пояснений и без markdown. Схема:
{"[поле1]": "строка", "[поле2]": число, "[поле3]": ["список строк"]}
Если данных нет — ставь null.

Скопируйте текст, замените слова в [квадратных скобках] на свои и отправьте нейросети.
