# Промтотека

Готовые промты для нейросетей и шпаргалки по их API — https://promoteka.tech

## Как изменить сайт

Всё содержимое лежит в папке `data/`, а `python3 build.py` собирает из него готовые страницы.

- `data/prompts.json` — промты: `cat` (раздел), `title`, `desc`, `text`, необязательные `link` (документация) и `added` (дата добавления — такие промты попадают в блок «Новое»). Места для заполнения пишите в [квадратных скобках]; одинаковые скобки заполняются одним полем.
- `data/guides/*.html` — гайды: сверху `title`, `h1`, `description`, затем строка `---` и текст статьи в HTML.
- `data/ai.json` — страницы «Промты для ChatGPT», «для Midjourney» и т. п.
- `data/site.json` — настройки: `metrika_id` (номер счётчика Яндекс Метрики), `telegram_channel` (ссылка на канал), `suggest_url` (куда отправлять предложенные промты), `start_here` (подборка «С чего начать»).

После правки запустите `python3 build.py` (нужен Python 3.12 или новее) — он пересоберёт все страницы, `sitemap.xml`, `robots.txt` и проверит, что внутренние ссылки не битые. Затем закоммитьте всё и отправьте в `main`: GitHub Pages обновит сайт примерно за минуту.

Новый раздел сначала добавьте в `build.py`: в словарь `CATS` (адрес и заголовки), в `CAT_CARD` (значок и короткое описание для главной) и на одну из полок в `SHELVES`. Оформление — в `style.css`, поведение в браузере (поиск, копирование, поля, избранное, тема, свои промты) — в `app.js`.

Не удаляйте `CNAME` (домен) и файлы `yandex_*.html`, `google*.html` (подтверждение в Яндекс Вебмастере и Google Search Console).
