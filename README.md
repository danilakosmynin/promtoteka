# Промтотека

Готовые промты для нейросетей и шпаргалки по их API — https://promoteka.tech

## Как изменить сайт

1. Промты лежат в `data/prompts.json`: у каждого есть `cat` (раздел), `title`, `desc`, `text` и необязательная `link`.
2. После правки запустите `python3 build.py` — он пересоберёт `index.html`, страницы разделов и промтов, `sitemap.xml` и `robots.txt`.
3. Закоммитьте всё и отправьте в `main` — GitHub Pages обновит сайт примерно за минуту.

Новый раздел сначала добавьте в словарь `CATS` в `build.py`. Оформление — в `style.css`, поиск, копирование и свои промты — в `app.js`.

Не удаляйте `CNAME` (домен) и файлы `yandex_*.html`, `google*.html` (подтверждение в Яндекс Вебмастере и Google Search Console).
