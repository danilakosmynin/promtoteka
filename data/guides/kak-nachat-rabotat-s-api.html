API — это способ обращаться к нейросети не через чат в браузере, а из своей программы: скрипта, сайта, Telegram-бота или таблицы. Вы отправляете запрос с текстом, а получаете ответ модели в формате JSON. Так работают почти все сервисы «на базе ChatGPT».

Шаг 1. Выберите провайдера

У каждой крупной нейросети есть свой API: OpenAI, Anthropic (Claude), Google (Gemini), Mistral, DeepSeek, GigaChat, YandexGPT. Если нужна оплата в рублях и работа без ограничений в России, посмотрите на GigaChat и YandexGPT. Если хотите бесплатно и без интернета — запустите модель на своём компьютере через Ollama.

Шаг 2. Получите ключ

Зарегистрируйтесь в кабинете разработчика провайдера, пополните баланс (у некоторых есть бесплатный стартовый лимит) и создайте API-ключ. Ключ — это пароль: по нему провайдер понимает, с чьего счёта списывать деньги.

  • Не публикуйте ключ в коде, на GitHub и в скриншотах.
  • Храните его в переменной окружения или файле .env, который добавлен в .gitignore — см. «Ключ в файле .env».
  • Не вставляйте ключ в код сайта, который выполняется в браузере: его увидит любой посетитель. Запросы к API делайте с сервера.
  • Поставьте лимит расходов в кабинете провайдера.

Шаг 3. Сделайте первый запрос

Проще всего начать с команды curl в терминале. Вот запрос к OpenAI-совместимому API — такой формат понимают OpenAI, DeepSeek, Mistral, Groq, OpenRouter и многие другие:

curl https://api.openai.com/v1/chat/completions \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "[название модели]",
    "messages": [{"role": "user", "content": "Привет!"}]
  }'

Название модели возьмите из документации провайдера — они часто обновляются. Готовые запросы для разных сервисов, на curl, Python и JavaScript — в разделе «API».

Шаг 4. Разберитесь со стоимостью

Платить нужно за токены — кусочки текста. Один токен — это в среднем 2–4 символа русского текста, точнее зависит от модели. Считаются и токены запроса (ваш текст, история переписки, системный промт), и токены ответа. Цена указывается за миллион токенов и сильно зависит от модели: маленькие модели в десятки раз дешевле флагманских.

Чтобы тратить меньше:

  • берите маленькую модель для простых задач — классификации, извлечения данных, коротких ответов;
  • ограничивайте длину ответа параметром max_tokens;
  • не отправляйте всю историю переписки, если она не нужна.

Шаг 5. Настройте ответ

Основные параметры запроса: temperature (насколько ответ творческий), max_tokens (предел длины), системный промт (роль и правила для модели). Подробнее — в шпаргалке «Основные параметры». Если нужен ответ, который разберёт программа, попросите модель отвечать в JSON — промт «Ответ в JSON».

Что дальше

Когда первый запрос заработал, можно добавить потоковый вывод, чтобы ответ появлялся по мере генерации, научить модель вызывать ваши функции (tool use) или передавать ей картинки. Примеры всех этих случаев — в разделе API.
