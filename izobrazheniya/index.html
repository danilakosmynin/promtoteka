Предметное фото

[товар] на [фон: белый / мрамор / дерево], студийная предметная съёмка, мягкий рассеянный свет, лёгкая тень, вид под углом 45°, малая глубина резкости, высокая детализация

Логотип

Простой минималистичный знак.

минималистичный логотип для [сфера / название], простая геометрическая форма, [1–2 цвета], плоский векторный стиль, белый фон, без мелких деталей, без текста

Иллюстрация

Для статьи или поста.

Интерьер

Визуализация комнаты.

интерьер [комната] в стиле [скандинавский / лофт / минимализм], [основные предметы], дневной свет из большого окна, светлые материалы, архитектурная фотография, широкий угол

Midjourney: параметры

Добавляются в конец промта.

--ar 16:9     соотношение сторон (1:1, 9:16, 3:2)
--v [номер]   версия модели
--stylize 100 сила художественного стиля (0–1000)
--chaos 20    разнообразие вариантов (0–100)
--no текст    чего не должно быть на картинке
--seed 1234   повторить похожий результат

Описать картинку для промта

Обратная задача: из изображения — промт.

Опиши прикреплённое изображение как промт для генератора картинок: объект, окружение, свет, цвета, стиль, ракурс, настроение. Одной строкой через запятые.

Слова в [квадратных скобках] замените на свои. Названия моделей меняются часто — актуальные смотрите в документации по ссылке. · Промтотека
