Потоковый ответ

API

Текст приходит по частям, как в чате.

Добавьте в тело запроса:
"stream": true

Ответ придёт как поток событий (Server-Sent Events): строки вида
data: {...кусок ответа...}
Последнее событие у OpenAI-совместимых API — data: [DONE]

Основные параметры

API

Что значат настройки запроса.

temperature   0–2   творчество: 0 — точно и одинаково, 1+ — разнообразно
max_tokens          предел длины ответа (1 токен ≈ 3–4 символа текста)
top_p         0–1   альтернатива temperature, меняйте что-то одно
stop                строки, на которых ответ обрывается
system              инструкция-роль для всей переписки

Anthropic (Claude) — потоковый ответ

API

Текст печатается по мере генерации. pip install anthropic

import anthropic

client = anthropic.Anthropic()  # ключ из ANTHROPIC_API_KEY

with client.messages.stream(
    model="[название модели]",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Расскажи короткую историю."}],
) as stream:
    for text in stream.text_stream:
        print(text, end="", flush=True)

Anthropic (Claude) — картинка на вход

API

Спросить модель о содержимом изображения.

import base64
import anthropic

client = anthropic.Anthropic()

with open("photo.jpg", "rb") as f:
    data = base64.standard_b64encode(f.read()).decode()

msg = client.messages.create(
    model="[название модели]",
    max_tokens=1024,
    messages=[{"role": "user", "content": [
        {"type": "image", "source": {"type": "base64", "media_type": "image/jpeg", "data": data}},
        {"type": "text", "text": "Что изображено на фото?"},
    ]}],
)
print(msg.content[0].text)

OpenAI-совместимые API из Python

API

Одна библиотека openai для DeepSeek, OpenRouter, Groq, Ollama и других.

import os
from openai import OpenAI

client = OpenAI(
    base_url="https://api.deepseek.com",  # адрес провайдера
    api_key=os.environ["DEEPSEEK_API_KEY"],
)

resp = client.chat.completions.create(
    model="[название модели]",
    messages=[{"role": "user", "content": "Привет!"}],
)
print(resp.choices[0].message.content)

# Другие адреса:
