Google Gemini — Python

Официальная библиотека: pip install google-genai

from google import genai

client = genai.Client()  # ключ из GEMINI_API_KEY

resp = client.models.generate_content(
    model="[название модели]",
    contents="Привет!",
)
print(resp.text)
