Ollama — Python

Локальная модель из кода: pip install ollama

import ollama

resp = ollama.chat(
    model="[модель]",
    messages=[{"role": "user", "content": "Привет!"}],
)
print(resp["message"]["content"])

# Сначала скачайте модель: ollama pull [модель]
