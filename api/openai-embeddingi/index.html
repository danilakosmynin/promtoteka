OpenAI — эмбеддинги

Векторы текста для поиска и рекомендаций.

curl https://api.openai.com/v1/embeddings \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "[модель эмбеддингов]",
    "input": "Как вернуть товар в магазин?"
  }'

# Ответ: data[0].embedding — список чисел.
# Похожие тексты сравнивают по косинусному сходству векторов.
