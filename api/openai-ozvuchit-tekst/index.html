OpenAI — озвучить текст

Текст в аудиофайл.

Заполнить поля · 1
curl https://api.openai.com/v1/audio/speech \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "[модель озвучки]",
    "input": "Привет! Это проверка синтеза речи.",
    "voice": "alloy"
  }' \
  --output speech.mp3
