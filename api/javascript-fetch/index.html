JavaScript — fetch

Запрос из Node.js или браузера (ключ не храните во фронтенде).

const resp = await fetch("[адрес API]", {
  method: "POST",
  headers: {
    "Authorization": `Bearer ${process.env.API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    model: "[модель]",
    messages: [{ role: "user", content: "Привет!" }],
  }),
});
const data = await resp.json();
console.log(data);

Подставьте свой ключ и название модели из документации.
