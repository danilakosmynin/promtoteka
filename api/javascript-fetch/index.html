JavaScript — fetch

Запрос из Node.js 18+. Ключ не храните в коде сайта — его увидит любой посетитель.

Заполнить поля · 2
const resp = await fetch("[адрес API]", {
  method: "POST",
  headers: {
    "Authorization": `Bearer ${process.env.API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    model: "[модель]",
    messages: [{ role: "user", content: "Привет!" }],
  }),
});
const data = await resp.json();
console.log(data);
