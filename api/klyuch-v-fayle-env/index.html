Ключ в файле .env

Чтобы ключ не попал в код и в Git.

# файл .env (добавьте его в .gitignore)
OPENAI_API_KEY=sk-...
ANTHROPIC_API_KEY=sk-ant-...

# Python: pip install python-dotenv
from dotenv import load_dotenv
load_dotenv()
